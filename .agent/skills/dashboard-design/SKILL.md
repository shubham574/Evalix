# Dashboard Design (`sickn33/agentic-awesome-skills/dashboard-design`)

## Core Principles
1. **Data Over Prose (Less Text, More Data):** Replace multi-sentence descriptions with scannable KPIs, compact spec chips, delta badges, and progress bars.
2. **Top-Level KPI Hierarchy:** Place 4 high-signal KPI cards at the top of the viewport, each showing a primary metric, comparison/delta or secondary ratio, and visual progress bar.
3. **Interactive Cross-Filtering:** Allow users to click KPI cards, mode tabs (`All`, `Voice`, `Mock`, `MCQ`), and chart type toggles (`Trend` vs `Bar`) to dynamically slice the dashboard data without page reloads.
4. **Actionable Quick-Launch Controls:** Provide 1-click preset selectors so users can jump straight into core workflows with pre-filled context.
5. **Clean Visual Grouping:** Use crisp `1px` borders, consistent card radii, tabular/monospace numbers for metrics, and semantic color coding (`#C7F36B` / `#1F8A4C` for strong performance, `#FF6B35` for active/warning, `#EF4444` for critical).
